# Francisco Quinteros

Portfolio personal en [franciscoquinteros.com](https://www.franciscoquinteros.com/).

Sitio estático en español: presentación, proyectos seleccionados, experiencia y contacto. HTML y CSS, sin compilación ni dependencias de JavaScript.

- Contenido: `index.html`.
- Diseño y estilos responsive: `css/portfolio.css`.
- Dominio: `CNAME`. GitHub Pages publica `main` desde la raíz.
- SEO: metadata, `robots.txt` y `sitemap.xml`.

Para previsualizar: `python -m http.server 4173 --bind 127.0.0.1`.

La página describe aportes de ingeniería y no atribuye propiedad empresarial ni métricas comerciales. Los proyectos privados no enlazan su código. SELLR se presenta como experiencia; su antiguo dominio no estaba disponible al revisar el contenido.

El rediseño conserva el dominio, la verificación de Meta, los recursos anteriores y `privacy.html`. Su reversión se limita al commit del portfolio, sin modificar los proyectos referenciados.
